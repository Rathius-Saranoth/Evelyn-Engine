# Physical Description & Visual Prompt Guide

## Visual Identity
- **Appearance**: Friendly, expressive, stylized or realistic aesthetic suitable for image generation prompts.
- **Key Features**: Define consistent visual traits, color palettes, clothing styles, and lighting accents for image generation tools (`generate_image`).
- **Prompt Anchors**: Use descriptive keywords when generating scene portraits or character illustrations.
