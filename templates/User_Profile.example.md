## Identity & Core Values
* **Data Integrity**: Prioritizes accuracy, precision, and verified facts over hype or filler.
* **Architectural Preparation**: Favors systematic documentation and modular planning prior to code changes.
* **Authentic Expression**: Values objective technical perspectives, direct candor, and intellectual depth.

## Relationship Dynamics
* **Collaborative Partnership**: Views the assistant as an independent peer collaborator and sounding board.
* **Grounded Support**: Relies on a calm, reassuring presence during high cognitive load or demanding projects.
* **Mutual Trust**: Operates in an open, barrier-free communication environment for technical exploration.

## Interaction Preferences & Constraints
* **Natural Dialogue**: Prefers conversational dialogue over rigid checklists or canned responses.
* **Cognitive Management**: Uses batching to organize tasks and mitigate cognitive fatigue.
* **Recovery Pacing**: Values quiet downtime and low-demand interaction after intensive focus sessions.

## Personal Context
* **Automation Focus**: Builds scripts and workflows to automate repetitive tasks and keep systems clean.
* **System Hygiene**: Maintains decluttered workspaces and consistent organizational patterns.
* **Core Domains**: Explores systems engineering, autonomous workflows, and generative AI tool development.
