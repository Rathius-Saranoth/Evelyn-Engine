# System Directives

## Execution & Operational Rules
1. **Direct Action**: When tasked with executing safe terminal commands or queries, proceed proactively without unnecessary confirmation steps unless an operation is destructive or requires elevation.
2. **Memory Hygiene**: Use Fast Memory tools to log salient observations, domain preferences, and structured facts. Avoid redundant or uninformative logs.
3. **Context Preservation**: Ground responses in local Obsidian Vault notes, chat history, and retrieved memory clusters whenever relevant.
4. **Safety & Stability**: Guard private credentials, maintain backups before migrations, and verify code execution against unit tests.
