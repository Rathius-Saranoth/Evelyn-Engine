# Evelyn Project: AI Instructions

This file serves as the primary guidance for AI Agents (Antigravity, Cursor, Copilot) working within the `LocalAI` workspace.

## 1. Project Context & Roadmap

Before searching for files, always refer to the following mapped locations:

- **Root Directory:** `C:\Projects\LocalAI`
- **Evelyn Tools:** `C:\Projects\LocalAI\Evelyn\tools` (Core logic, ingestion, and management scripts)
- **Reference Docs:** `C:\Projects\LocalAI\reference` (System prompts, persona data, and RAG configs)
- **External Dependencies:**
  - Obsidian Vault: `G:\My Drive\Obsidian_Vault`
  - ComfyUI: `C:\Projects\ComfyUI`
  - Scripts: `C:\Projects\Scripts`

## 2. Coding Standards

### Python Docstrings

- **Requirement:** Every script and major function MUST have a Google-style docstring.
- **Goal:** Enable the AI to understand the script's purpose via tool inspection without reading the full source.
- **Reference:** See the guide in the brain artifact for detailed examples.

### Markdown Instructions

- **Requirement:** Use GitHub-style Alerts (`> [!IMPORTANT]`, `> [!NOTE]`) for mission-critical instructions within `.md` files.

## 3. Workflow & Automation

- **Service Startup:** If services (Ollama, Open WebUI, etc.) are down, refer to `tasks.json` or the `.agents/workflows/start-services.md` workflow.
- **Avoid Redundant Searches:** If a path is listed in Section 1 or in `reference/related_projects_locations.md`, use it directly rather than using `find_by_name`.

## 4. Maintenance & State Tracking

### Roadmap Updates

> [!IMPORTANT]
> `ROADMAP.md` in the root is the **canonical, persistent project tracker**. It is the single source of truth for completed phases and upcoming goals.
>
> - **Always update `ROADMAP.md`** after completing any significant milestone or feature.
> - **Do NOT create a separate project roadmap or master task list.** Session-scoped `task.md` artifacts (stored in the Brain directory) are acceptable for tracking work within a single conversation, but they must not be treated as substitutes for or duplicates of `ROADMAP.md`.
> - When starting a new session, read `ROADMAP.md` first to understand project state before making plans.
